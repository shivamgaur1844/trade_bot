# Automated Trading Bot

A professional-grade automated trading dashboard integrated with Angel One SmartAPI, featuring advanced risk management and multi-indicator strategy execution.

## Features
- Real-time market data visualization.
- Automated Option Engine (Strike selection, Moneyness control).
- Multi-indicator strategy (EMA, RSI, MACD, Bollinger Bands).
- Dynamic risk management (Take-Profit & Stop-Loss).
- Production-ready Flask web server.

## Deployment
Prepared for deployment on Render/Heroku with `Procfile` and `requirements.txt`.

## Disclaimer
Trading involves risk. This bot is for educational and demo purposes. Always test in a paper trading environment first.
